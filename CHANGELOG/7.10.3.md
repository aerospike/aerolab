# [v7.10.3](https://github.com/aerospike/aerolab/releases/tag/7.10.3)

_Release Date: June 15th, 2026_

**Release Notes:**

* Upgrade go to 1.26.
* Upgrade expiry system build version in GCP to 1.26.
* Fix cost account bug for instances in STOPPED state.
* Add missing Operating System versions into the supported matrix.
* `client create ams`: fix the Grafana fallback installer downloading the `amd64` package on arm64 hosts. Architecture detection matched `uname` output against `arm`, which does not match the `aarch64` reported by Linux on Graviton, so `dpkg -i` failed with `package architecture (amd64) does not match system (arm64)`.
